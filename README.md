# 🛒 Shopzy – Modern E-Commerce App  

Shopzy is a **modern e-commerce web application** built as a practice project to learn **real-world e-commerce workflows** – from browsing categories to managing cart, checkout, and orders.  
This project is inspired by [Hitesh Choudhary](https://github.com/hiteshchoudhary)’s open-source e-commerce backend 🚀.  

---

## ✨ Features  

- 🏷️ **Categories & Product Pages** – Browse products by categories
- 🛒 **Cart & Checkout** – Add, remove, and update cart items  
- 📦 **Address Management** – Add / delete multiple saved addresses  
- 👤 **User Authentication** – Login, Register, and Profile management  
- 🚪 **Logout States** – Clean UI messages when logged out (cart, profile, etc.)  
- 🎨 **Modern UI/UX** – Emoji-based categories, carousel navigation

---

## 🏗️ Tech Stack  

- **Frontend:** HTML, CSS, JavaScript  
- **Backend API:** [Open-source e-commerce backend]([https://github.com/hiteshchoudhary](https://github.com/MAHasnain/Backend-app)) by Hitesh Choudhary  
- **Database:** MongoDB (via backend)

## 🚀 Getting Started  

1. Clone this repository  
   ```bash
   git clone https://github.com/MAHasnain/ShopZy-app.git
   cd shopzy
   ```  

2. Open `index.html` in your browser  

3. Make sure backend API is running and update `BASEURL` in `app.js`
